This is a repository for the roblox game An Adventure at the Mall. The game is a roguelite adventure game about conquering scenarios at a mall. Test it out here: https://www.roblox.com/games/98899210633034/An-Adventure-at-the-Mall



How to run:

NOTE: you'll need a roblox account to play this game. Don't worry; you don't have to hook up an email to it. Simply head to roblox.com, enter your birthday (real, it will require an age check when you go to play the game unfortunately), put in a username and password, and hit sign up.



Open the website above. There's a big blue play button; press that. It will prompt you to download roblox (if you don't already have it); please download it and open the executable. It should simply install and open. Once it does, go back to the website and hit the play button again.



If you don't want to create an account or verify your age (cause roblox requires that), go ahead and download a version of the game yourself. You can do this by hitting the three dots just to the right of the name and clicking "Edit in Studio." Note that you have to have Roblox studio installed (if you don't, head to create.roblox.com, hit "Start Creating," and download Roblox Studio using the above download instructions for roblox). Once you log in and open the project, look at the top left of your screen; there should be a small blue play button (►); click this to begin playing.



How to play:

Head inside the mall and chat with NPCs using E when you get close to them.

The scenario will start 30-45 seconds after you start playing. Follow your objectives on the side of the screen to proceed.

If you're confused about certain objectives, asking NPCs (ones you still get along with) can clue you in. The exit doors in the blackout scenario are blocked out by large black parts; simply run into them to check whether or not they are open.

Note that this game is in an extremely early build and certain things may break. Report what happened in the review and I will fix it ASAP. If something says it's supposed to break, it's really not but I haven't programmed its functionality yet oops :(



The Making of the game:

I decided to start this project a while back because I wanted to make a fun, very replayable game that wasn't a copy of another game or a quick pay-to-win cashgrab. Roblox has recently been filling up with a ton of carbon copies and p2w cashgrabs and I want to throw something out there that's actually fun. Also I wanted to learn how to make complex NPC dialogue and build a cool mall.

I made this through Roblox Studio because I have been working with this platform for a couple years now. It is coded in Luau and has multiple scripts, both client and server (mostly server), running operations to make it work properly. Minimal control has been given to the client to avoid exploiting; more exploitation prevention will be added as the game nears a finished product. You can copy the experience's source code and view it for yourself if you want to dig a little deeper.
